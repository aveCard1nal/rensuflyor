# RenSuflyor

Синхронный машинный перевод диалогов игр на Ren'Py на русский язык через Google Translate или Яндекс Переводчик.

Весь мод — один файл `zz_rensuflyor.rpy`, который кладётся в папку `game/` игры.

Поддерживаются Ren'Py 7 (Python 2.7) и Ren'Py 8 (Python 3).

## Установка

1. Скачайте `zz_rensuflyor.rpy` со страницы [Releases](https://github.com/aveCard1nal/rensuflyor/releases).
2. Положите его в папку `game/` игры, рядом с файлами `.rpa` и `.rpy`.
3. Запустите игру. Реплики и варианты ответа будут переводиться автоматически.

Чтобы удалить, удалите `zz_rensuflyor.rpy` и `zz_rensuflyor.rpyc` из папки `game/`.

## Как работает

- Реплики и пункты меню перехватываются через `config.say_menu_text_filter`.
- Фоновый поток заранее переводит до 40 реплик вперёд по графу скрипта, включая все ветки меню, `if`, `jump` и `call`.
- Если перевод ещё не готов, игра ждёт до 3 секунд, а потом показывает оригинал.
- Переводы копятся в `game/rensuflyor_cache_ru_<переводчик>.jsonl`. Если папка игры недоступна для записи, кэш пишется в папку сохранений.
- Тэги Ren'Py, подстановки `[...]`, `%%` и паузы `{w}`/`{nw}` сохраняются.

## Настройки

В игре настройки открываются клавишей F8:

- переводчик: Google (по умолчанию) или Яндекс;
- переводить ли имена персонажей (`Character`), по умолчанию нет;
- включить или выключить перевод; когда перевод выключен, показывается оригинал;
- показывать оригинал мелким шрифтом под переводом;
- шрифт для кириллицы: «от игры + DejaVuSans» (кириллица берётся из DejaVuSans, только если в шрифте игры её нет) или «только DejaVuSans»;
- открыть список игнорирования `game/rensuflyor_glossary.txt`: слово или фраза на строку, применяется после закрытия окна;
- сбросить кэш переводов текущего переводчика.

Значения хранятся в `persistent` игры. Значения по умолчанию задаются блоком в начале собранного файла: `provider`, `translate_names`, `settings_key`, `font_fallback`.

## Конфиденциальность и ограничения

- Тексты реплик отправляются в Google Translate или Яндекс Переводчик. Другие данные не отправляются. Для Яндекса в `persistent` игры хранится случайный идентификатор установки.
- Используются неофициальные бесплатные адреса этих сервисов без ключа. Они могут ограничить число запросов или перестать работать.
- Нужен интернет. Без сети показывается оригинал.

## Сборка

```
python build.py
```

## Тесты

```
python -m unittest discover -s tests -t .
```

В комплекте игр на Ren'Py 7 урезанная стандартная библиотека без `unittest`, поэтому совместимость с Python 2.7 проверяется прогоном внутри игры.

Проверка на полном корпусе строк игры запускается, если задана переменная `RENSUFLYOR_CORPUS` (см. `docs/experiments.md`).
