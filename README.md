# renpy-autotranslate

Синхронный машинный перевод диалогов игр на Ren'Py на русский язык через Google Translate или Яндекс Переводчик.

Результат сборки — один файл `dist/zz_autotranslate_ru.rpy`, который кладётся в папку `game/` игры.

Поддерживаются Ren'Py 7 (Python 2.7) и Ren'Py 8 (Python 3).

## Как работает

- Реплики и пункты меню перехватываются через `config.say_menu_text_filter`.
- Фоновый поток заранее переводит до 40 реплик вперёд по графу скрипта, включая все ветки меню, `if`, `jump` и `call`.
- Если перевод ещё не готов, игра ждёт до 3 секунд, а потом показывает оригинал.
- Переводы копятся в `game/rtr_cache_ru_<переводчик>.jsonl`. Если папка игры недоступна для записи, кэш пишется в папку сохранений.
- Тэги Ren'Py, подстановки `[...]`, `%%` и паузы `{w}`/`{nw}` сохраняются.

## Настройки

В игре настройки открываются клавишей F8:

- переводчик: Google (по умолчанию) или Яндекс;
- переводить ли имена персонажей (`Character`);
- показывать оригинал вместо перевода;
- открыть список игнорирования `game/rtr_glossary.txt`: слово или фраза на строку, применяется после закрытия окна;
- сбросить кэш переводов текущего переводчика.

Значения хранятся в `persistent` игры. Значения по умолчанию задаются блоком в начале собранного файла: `provider`, `translate_names`, `settings_key`.

## Сборка

```
python build.py
```

## Тесты

```
python -m unittest discover -s tests -t .
```

В комплекте игр на Ren'Py 7 урезанная стандартная библиотека без `unittest`, поэтому совместимость с Python 2.7 проверяется прогоном внутри игры.

Проверка на полном корпусе строк игры запускается, если задана переменная `RTR_CORPUS` (см. `docs/experiments.md`).
