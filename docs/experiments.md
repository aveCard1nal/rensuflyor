# Эксперименты

## 01. Маркеры разметки через Google Translate (2026-11-01)

Корпус: Being a DIK, Seasons 1–2 и Season 3, Ren'Py 7.4.10. 99 009 строк (реплики и пункты меню), разметка в 5 186.

Выборка: 202 сегмента с `{i}`, `{b}`, `{color}`/`{size}`/`{font}`, `[interp]`, `{w}`/`{nw}`, `\n`, `%%`.

Эндпоинт: `POST https://translate.googleapis.com/translate_a/t?client=gtx&sl=en&tl=ru&format=<html|text>`, до 20 `q` в одном запросе.

| Схема | Формат | Подстановки | Маркеры целы | Артефакты пробелов |
|---|---|---|---|---|
| S1 | html | `<x id=N></x>` | 202/202 | 53 пробела перед пунктуацией, 20 слипшихся `[name]` |
| S2 | text | `<x id=N></x>` | 202/202 | 0 |
| S3 | html | `<span translate="no">name</span>` | 202/202 | 62 пробела перед пунктуацией |

Выводы:

- По умолчанию используем `format=text` с теми же HTML-маркерами. Google в текстовом режиме сохраняет теги и не трогает пробелы вокруг них.
- В текстовом режиме Google сам раскодирует `&amp;` в `&`, наш `html_unescape` к этому устойчив.
- `format=html` остаётся запасным вариантом, но ему нужна чистка пробелов перед пунктуацией и вокруг атомов.
- Подстановка-слово внутри `translate="no"` (S3) грамматику заметно не улучшила.
- Игровые термины (названия характеристик, рангов и т. п.) переводятся дословно. Встроенного глоссария под конкретные игры не будет: только необязательный пользовательский файл `rtr_glossary.txt` в `game/`, слова из которого уходят как атомы.
- Одна и та же реплика может получить «ты» или «вы» в разных запросах. Повлиять на это нельзя, кэш хотя бы делает выбор стабильным для каждой строки.

Воспроизвести:

```
python tools/rpa.py <out_dir> <game>/game/*.rpa
python tools/rpyc.py <out_dir> corpus.json
python tools/experiment.py corpus.json experiment.json
```
